# ⛵ Yacht Scoring

A streamlined, cloud-based micro-SaaS tool designed specifically for small-to-mid yacht clubs to manage sailboat race series.

Our mission is to eliminate the pain of manual data entry, complicated spreadsheets, and aging desktop software (like Sailwave) by providing instant, frictionless scoring and live standings for race committees and fleets.
