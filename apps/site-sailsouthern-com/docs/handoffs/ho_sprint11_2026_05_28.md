## 3. Technical Debt & Open Questions

* **Next.js Server Dynamic Errors**: Next.js 16 enforces strict runtime compilation flags during static page exports. Any components loading search parameters dynamically must execute under `Suspense` wraps or server-side dynamic context to prevent dynamic-server prerender crashes.
* **Crypto Key Generation**: The ActivityPub Actor signature verification is stubbed. A background key generator script is required to generate RSA-256 private/public key pairs for each registered entity actor.
* **Outbound Delivery**: Follow tracking is fully operational in the database, but a queue worker is needed to post outbound JSON payloads (e.g. daily editions) to remote actor inboxes.
