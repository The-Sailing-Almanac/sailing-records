## Architectural Decisions

1. **Index name `article_links`** — Aligns with `/api/search` and Sprint 5 frontend; replaced API startup index `articles`.
2. **Public corpus filter** — Suppressed and very-low relevance rows stay in Postgres but are excluded from Meilisearch via `--public-only` indexing and search API filter.
3. **Heuristic scoring before Gemini** — Resets default `relevance_score = 1.0` to NULL, then bulk-scored in 5k batches to avoid API cost on 337k low-signal links.
4. **Feed validator as separate BullMQ queue** — `feed_validation` queue, max 10 concurrent HTTP checks, does not touch `live_ingest` / `archival_backfill`.
5. **Prebuilt dist in Docker** — `Dockerfile.feed-validator` copies compiled `dist/` to avoid TS build failures in container; ingest Dockerfile unchanged for full builds.
