## 1. Batch A Status — Data Quality, Redirect System & Symbol Library (Complete)

- **Redirect System `/r/:hash` / `/sendit/:hash`**: Fully active. Every outbound link on the site and in the daily/weekly newsletters routes through a tracked redirection. IP addresses are hashed using SHA-256 before being recorded in the database to preserve user privacy. 
- **OG Image Extraction**: Automatic background worker extracts `og:image` meta tags from the first 32KB of ingested pages and stores them in `article_links.og_image_url`. Serves them direct from source URLs (fair-use thumbnails) on the site.
- **Symbol Library**: Created custom SVG icons inside `/apps/web/public/symbols/` (compass, anchor, wind, wave, helm, flag) with a TypeScript-typed `<Symbol />` component.
- **Data Quality Scoring**: Script calculates a weighted quality score in `[0.0, 1.0]` based on title, content snippet, dek, og_image_url, and publication details. Articles scoring below 0.5 are flagged as low quality.
- **Nginx & API rate limits**: Configured to 120 req/min/IP for redirect links to prevent crawler scraping/spam.

## 2. Batch B Status — Editorial Engine, Entity Graph & Feed Builder (Complete)

- **Editorial Engine**: Homepage displays the daily compiled edition compiled at 6 AM. Historical daily pages (`/daily/[date]`) and topic archive pages are fully live.
- **Entity Graph**: Seeding script upserted 10 entity types and 76 starter entities. BullMQ-based entity extraction worker parses ingested snippets using Gemini 2.5 Flash and logs `entity_mentions` mapping. Dynamic public-facing profile pages are generated at `/entities/[slug]`.
- **Feed Builder**: Exposes `/api/feeds/combined` to construct multi-entity dynamic feeds. The interactive feed builder page at `/builder` allows users to select entities, preview the feed, and copy the canonical RSS feed URL.
- **Email Subscriptions**: Implemented `POST /api/subscribe`, `/api/subscribe/confirm/:token`, and `/api/unsubscribe` endpoints wired to Resend.

## 3. Batch C Status — Monetization, Analytics, Cron & Wayback Pilot (Complete)

- **Supporter Tiers & Supporters Page**:
  - Seeded 6 supporter tiers: Free Reader ($0), Supporter ($50/yr), Founding Member ($100), Patron ($250), Lead Patron ($500), and Weekly PWYW ($0+).
  - Public directory at `/supporters` shows active, non-anonymous supporters grouped by tier.
  - Interactive `/support` stub page lists features and contains payment stubs.
  - Manual creation endpoints (for admin/webhook integration) are fully functional.
- **GA4 Analytics Endpoint**:
  - Endpoint `GET /api/admin/analytics` integrates with the Google Analytics 4 Data API using `@google-analytics/data`.
  - Gracefully handles unconfigured environment variables by returning a JSON message pointing to setup documentation instead of crashing.
- **Admin Dashboard `/admin`**:
  - Features tabbed layout: Overview, Content, Submissions, Analytics, Supporters.
  - Interfaces with database stats, Meilisearch index size, submissions workflow, and supporter gifts tracking.
- **Wayback Feed Discovery Pilot**:
  - Script `/scripts/wayback-feed-discovery.ts` was written, copy-synced to `chantecler-01`, and run.
  - Adheres to the **Feed Permanence Doctrine** by maintaining reference links in `feed_endpoints.wayback_url` rather than deleting or mutating original records.
  - **Results & Recommendation**: Out of 100 inactive feeds sampled, 99 failed with timeout/fetch failures. The CDX API returned 504 Gateway Time-outs due to Archive.org stability issues, and the sampled defunct URLs are tracked email parameters. We **recommend against** a full Wayback backfill worker at this time until CDX API stabilizes and tracking domains are filtered out.
- **Submit Endpoint**:
  - Fully wired at `/submit` and `/api/submissions`. Public submissions trigger instant multi-channel Discord/Slack/Telegram broadcast alerts.
